# 별빛 모험단

친구와 함께 섬을 모험하는 **3D 협동 액션 RPG** 웹게임입니다. 설치 없이 브라우저에서 바로 하고, 패드(터치)와 PC 모두 지원합니다.
공개 월드 하나에 모두가 함께 들어오고, 몬스터만 상대하는 PvE 게임이에요. 닉네임만 정하면 바로 시작합니다.

**바로 플레이:** https://tvttvvv.github.io/web-game/

## 할 수 있는 것

- **직업 4가지**: 전사 · 궁수 · 마법사 · 성직자. 직업마다 기본 공격과 스킬 4개(레벨 1 · 4 · 8 · 15에 배움)
  - 전사: 회전베기 · 돌진 베기 · 전투의 함성(적을 끌어모음) · 대지 가르기(기절)
  - 궁수: 다발 사격 · 화살비 · 질풍(뒤로 물러나며 강화) · 폭풍 화살(관통)
  - 마법사: 화염구 · 얼음 폭풍(감속) · 순간이동 · 메테오
  - 성직자: 치유의 빛 · 신성한 심판(기절) · 수호의 축복 · 부활의 기도
- **성장**: 레벨 1~30, 경험치 · 골드, 레벨이 오르면 체력/공격력 등이 오르고 새 스킬이 열려요
- **장비**: 무기 · 투구 · 갑옷 · 신발 · 장신구 5부위, 등급 5단계(일반 · 고급 · 희귀 · 영웅 · 전설)와 무작위 추가 옵션, 대장장이에게 **+10까지 강화**
- **넓은 섬**: 새벽 마을(안전 지대) → 초록 들판 → 고요한 호수 → 속삭이는 숲 → 붉은 바위 협곡 → 불타는 황무지(용암 주의)
- **몬스터 14종 + 보스 4마리**: 슬라임 킹 · 숲의 수호자 · 고대 골렘 · 용암 거인. 보스는 바닥에 빨간 경고를 띄우고 강한 공격을 하니 피하세요
- **퀘스트 16개**(이야기 순서대로 이어짐) + 반복 **현상금 의뢰**, 퀘스트 목표는 지도와 화살표로 안내
- **마을**: 촌장 · 잡화 상인 · 대장장이(장비 구매/강화) · 여관(무료 회복) · 현상금 게시판, 야영지마다 상인
- **이동의 돌**: 야영지의 돌에 가까이 가면 등록되고, 어느 돌에서든 순간이동
- **함께 하기**: 다른 모험가를 눌러 **파티 초대**(최대 4명, 경험치 공유), 쓰러진 동료 일으키기, 공개/파티 채팅(`/p 메시지`, `/who`)
- **편의**: 자동 타겟 · 꾹 누르면 자동 공격, 몬스터/NPC를 누르면 그쪽으로 이동, 미니맵 · 전체 지도, 효과음, 그래픽 설정

## 실행 방식

### 1. GitHub Pages (서버 없이, P2P)
이 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 `public/`을 Pages로 배포합니다.
서버가 없으면 게임이 **P2P 모드**로 동작해요.
- 처음 들어온 사람의 브라우저가 게임을 계산하는 **호스트**가 되고, 다른 사람은 그 브라우저에 접속합니다 (연결 중개: PeerJS 무료 서버).
- 호스트가 나가면 남은 사람 중 한 명이 자동으로 이어받고, 모두 **있던 자리에서 그대로** 계속합니다.
- 잠들었던 호스트가 다시 깨어나 월드가 둘로 갈라지면, 사람이 적은 쪽이 많은 쪽으로 자동으로 합쳐집니다.
- 친구끼리만 하고 싶으면 주소 뒤에 `?room=방이름`을 붙이세요 (예: `https://tvttvvv.github.io/web-game/?room=class3`). 같은 방 이름을 쓴 사람끼리만 만나요. 방 이름은 영문 소문자 · 숫자 · `-`만 쓸 수 있어요.
- 일부 모바일 데이터망이나 회사·학교 와이파이에서는 P2P 연결이 막힐 수 있습니다.

### 2. Node 서버 (항상 켜 둔 월드)
```bash
npm install
npm start          # http://localhost:3000
npm test           # 게임 로직 + 서버 스모크 테스트
```
서버가 있으면 자동으로 **서버 모드**가 됩니다. Codespaces(`.devcontainer/`)나 Render(`render.yaml`)로 바로 띄울 수 있어요.
