# 픽셀 커먼스 3D

모두가 같은 월드에서 함께 사는 **3D 복셀 공개월드 · 협동 PvE · 샌드박스** 웹게임입니다. 패드(터치)와 PC 모두 지원합니다.

**바로 플레이:** https://tvttvvv.github.io/web-game/

## 할 수 있는 것

- **무한 3D 월드**: 평원 · 숲 · 자작나무 숲 · 침엽수림 · 설원 · 사막 · 산 · 해변 · 바다, 동굴과 광물(석탄 · 철 · 금 · 다이아몬드)
- **캐기와 짓기**: 블록 130여 종(판자, 벽돌, 유리, 등불, 계단, 반 블록, 문, 사다리, 표지판, 침대, 양털 16색 …)
- **조합 80여 가지**: 작업대 · 화로, 나무 → 돌 → 철 → 다이아몬드 도구(곡괭이 · 도끼 · 삽 · 검 · 괭이)
- **생존**: 체력 · 배고픔 · 숨 쉬기, 낮과 밤(12분), 밤과 동굴의 좀비 · 슬라임 (좀비는 햇빛에 타요)
- **동물과 농사**: 돼지 · 양 · 닭 사냥, 화로에 굽기, 괭이로 밭을 갈아 밀을 키우고 빵 만들기, 묘목 심기
- **함께 살기**: 공개 채팅과 말풍선, 표지판 글쓰기, 공용 상자, 깃발로 땅 보호(17×17), 스폰 광장 보호
- **편의**: 침대로 부활 지점 지정, `/spawn` `/home` `/who` 명령, 도전 과제 18개, 1인칭/3인칭 시점, 효과음

## 실행 방식

### 1. GitHub Pages (서버 없이, P2P)
이 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 `public/`을 Pages로 배포합니다.
서버가 없으면 게임이 **P2P 모드**로 동작해요.
- 처음 들어온 사람의 브라우저가 월드를 계산하는 **호스트**가 되고(🏠 표시), 다른 사람은 그 브라우저에 접속합니다 (연결 중개: PeerJS 무료 서버).
- 호스트가 나가면 남은 사람 중 한 명이 **최신 월드 사본으로 자동으로 이어받습니다** (보통 5~15초).
- 월드는 브라우저 저장소에도 저장되고, 다른 기기에 남아 있던 변경도 접속할 때 합쳐집니다. 지형은 고정 시드라 모두 같아요.
- 일부 모바일 데이터망이나 회사·학교 와이파이에서는 P2P 연결이 막힐 수 있습니다.

### 2. Node 서버 (항상 켜 둔 월드)
```bash
npm install
npm start          # http://localhost:3000
npm test           # 호스트 로직 + 서버 스모크 테스트
```
서버가 있으면 자동으로 **서버 모드**가 되고, 월드는 `data/world3.json`에 저장됩니다(`DATA_DIR`로 위치 변경). Codespaces(`.devcontainer/`)나 Render(`render.yaml`)로 바로 띄울 수 있어요.

```
  js/net.js                  서버(WebSocket) / P2P(PeerJS) 연결, 호스트 이어받기
  js/shared/                 서버·호스트·클라이언트 공용

    worldgen.js noise.js     결정적 지형 생성 (바이옴, 동굴, 광물, 나무, 스폰 광장)

    world.js game.js         월드 저장, 플레이어, 조합, 상자, 몹 AI, 농사, 땅 보호 …

    textures.js icons.js     코드로 그린 픽셀아트 텍스처와 아이콘
    worker.js mesher.js      웹 워커에서 지형 생성 + 빛 전파 + 부드러운 조명/AO 메시
    renderer.js chunks.js    Three.js 장면, 하늘 · 해 · 달 · 별 · 구름, 청크 관리
    entities.js player.js    플레이어 · 몹 모델, 1인칭 손, 내 캐릭터 물리
    input.js ui.js audio.js  터치/키보드/마우스, 화면 UI, 합성 효과음
server/                      Node 서버 (정적 파일 + WebSocket + 저장)
test/                        core.mjs (게임 로직), smoke.mjs (서버 접속)
```
