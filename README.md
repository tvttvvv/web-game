# 픽셀 커먼스

모두가 같은 월드에 접속하는 **공개월드 · PvE 협동 · 샌드박스** 픽셀 웹게임. 패드(터치)와 PC 모두 지원합니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000  (PORT=8080 npm start 로 포트 변경)
npm test           # 서버 스모크 테스트
```

같은 네트워크의 패드에서는 `http://<PC의 IP>:3000` 으로 접속하세요.
월드는 `data/world.json`에 5초마다 자동 저장됩니다 (`DATA_DIR`로 위치 변경).

## 플레이

| 조작 | 터치 | PC |
|---|---|---|
| 이동 | 왼쪽 아래 조이스틱 | WASD / 방향키 |
| 채집·건축 | 화면의 칸을 터치 | 마우스 클릭 |
| 공격 | ⚔️ 버튼 (또는 몬스터 터치) | Space |
| 모드 전환 | ⛏️/🧱 버튼 | B |
| 블록 선택 | 팔레트 터치 | 1~4 |
| 채팅 | 💬 | Enter |
| 닉네임 변경 / 조작법 | ✏️ / ❓ | — |

- **마을(반경 12칸)** 은 안전지대: 몬스터가 못 들어오고 건축/채집이 금지됩니다. 자원은 마을 바깥에 있어요.
- **🚩 깃발** (나무10+돌5): 세우면 주변 15×15가 내 땅이 되어 다른 사람이 건축/파괴할 수 없습니다 (최대 3개).
- **바닥** 블록은 물 위에도 놓을 수 있어 다리를 만들 수 있습니다.
- 하루 5분 주기. **밤**에는 슬라임이 나타나고 벽으로 막을 수 있어요. 아침이 되면 사라집니다.
- 쓰러지면 마을에서 부활 (아이템 손실 없음).

## 구조

```
server/index.js        HTTP 정적 서빙 + WebSocket (서버 모드)
server/world.js        월드 파일 저장/불러오기
public/js/core/world.js  시드 기반 청크 지형 생성 (서버·브라우저 공용)
public/js/core/game.js   권위 시뮬레이션: 이동/채집/건축/몬스터/영역 (서버·P2P 호스트 공용)
public/js/net.js       서버(WebSocket) / P2P(PeerJS) 연결
public/js/shared.js   서버·클라 공용 상수와 이동·충돌 로직
public/js/render.js   절차적 픽셀아트 + 캔버스 렌더링
public/js/main.js     네트워크, UI, 클라이언트 예측
```

- 접속하면 랜덤 게스트 닉네임으로 **바로 입장** (✏️로 변경).
- 계정 없이 **닉네임 게스트**: 브라우저가 랜덤 토큰을 저장하고 서버는 해시로 진행(인벤토리·킬)을 기억합니다.
- 월드는 32×32 청크로 무한 생성되며, 플레이어가 바꾼 타일만 저장합니다.
- PvP 없음: 플레이어끼리 피해를 줄 수 없습니다.

## 배포 (무료)

**0. GitHub Pages — 서버 없이 바로 (`https://tvttvvv.github.io/web-game/`)**
`gh-pages` 브랜치에 `public/` 폴더 내용을 올리면 됩니다. Node 서버가 없으면 게임이 자동으로 **P2P 모드**가 됩니다.
- 처음 들어온 사람의 브라우저가 월드를 돌리는 **호스트**가 되고(🏠 표시), 나머지는 그 브라우저에 접속합니다 (연결 중개: PeerJS 무료 서버).
- 호스트가 나가면 남은 사람 중 한 명이 마지막 월드 사본으로 이어받습니다. 호스트가 갑자기 꺼지면 이어받기까지 최대 1분 정도 걸릴 수 있어요.
- 월드는 호스트 기기의 브라우저 저장소에 저장되며, 모두가 나가면 마지막 호스트 기기에 남습니다.
- 일부 모바일 데이터망/회사망에서는 P2P 연결이 막힐 수 있습니다.

**A. GitHub Codespaces — 임시 공개 주소**
저장소 → Code → Codespaces → Create. 열리면 서버가 자동 실행되고, 포트 탭의 3000번 주소(`*.app.github.dev`)가 공개됩니다. 공개가 안 되어 있으면 포트 탭에서 3000번을 우클릭 → Port Visibility → Public.

**B. Render 무료 플랜 — 상시 주소**
1. https://render.com 가입 → New → **Blueprint** → 이 저장소 선택 (`render.yaml` 자동 인식)
2. 배포가 끝나면 `https://pixel-commons-xxxx.onrender.com` 주소가 생깁니다.
- 무료 플랜은 15분간 접속이 없으면 잠들고(첫 접속 시 약 30초 대기), **재시작하면 월드가 초기화**됩니다 (영구 디스크는 유료).
